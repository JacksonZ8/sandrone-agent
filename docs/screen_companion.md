# 看屏（看一眼 · 陪着看 · 游戏场景）

原来的「屏幕观察」（M9）、「陪你用电脑」（M14）和「陪你玩游戏」（M15）合并为一个只读的**看屏**功能，按“谁开口、看多久”分两档：

| | 看一眼 | 陪着看 |
|---|---|---|
| 谁发起 | 你说“看看我的屏幕 / 这张牌该不该拿 / 讲讲这道题” | 设置里常开，或你说“这局陪我看着” |
| 看几次 | 一次，当场回答 | 每隔几分钟一次，到点或你说“别看了”就停 |
| 她开口 | 回答你的问题 | 多数时候安静，偶尔说一句 |
| 工具 | `look_at_screen` | `watch_screen`（语音临时开）/ 设置常开 |

**游戏不是单独的功能，而是看屏时自动识别的场景**：前台是建过档的游戏时只截游戏窗口、带上账号档案和游戏知识；认出没建档的游戏会自动加进「游戏」页（标“自动识别”，默认不写战报）。

两档都只读、不做任何键鼠操作。会动键鼠的**帮你操作电脑**（M10 Computer Use）是另一回事，仍然搁置，本仓库不包含。

## 看一眼

设置页「她能做什么」→ 打开「看一眼屏幕」；视觉模型在「高级」里（留空复用对话模型的地址与 Key）。你让她看时她才截图：

1. 前台应用对得上某个游戏档案 → 只截这个游戏窗口，提示里带上账号档案、相关游戏知识，回答后这一场算“正在玩”，接下来十几分钟的对话都带着这个游戏的上下文；
2. 屏幕上有她不看的应用（见下面的“不看的应用”）→ 只截她可以看的最前面的窗口，整屏截图不会带上密码或聊天；屏幕上只有不看的应用、或读不到窗口信息时不截；
3. 否则截整个屏幕。

视觉模型除了回答问题，还判断画面是不是一款游戏；是的话按游戏名建档（浏览器里的不算）。截图分析后即删除。

## 陪着看：怎么开

两种开法，都需要先同意一次把窗口截图发给视觉模型（在「她能做什么」里第一次打开「陪着你看」时会问）：

- **常开**：在「她能做什么」里打开「陪着你看」。她看你正在用的应用，**不看的应用除外**，不用再挑名单。看的间隔（默认 5 分钟）、她开口的频率（默认最多 45 分钟一句，可选「只看不说」）和不看的应用在「高级 → 陪着看」里调。

### 不看的应用

- **永远不看（不能放开）**：1Password、Bitwarden、KeePassXC 等密码管理器，钥匙串访问、「密码」，系统设置，以及桑多涅自己的窗口。
- **默认不看（可以在「高级 → 陪着看」里放开或再添加）**：微信、QQ、信息、Telegram、WhatsApp、Signal、邮件、支付宝。银行等其他应用名字因人而异，需要时自己加。
- 不看的应用连名字都不记录；「看一眼」时屏幕上有它们，就只截她能看的窗口。
- **语音临时开**：聊天或通话里说“这局陪我看着”“接下来看着我写代码”，她调用 `watch_screen`，从现在起只看**当前前台的那个应用**，默认 1 小时（最多 4 小时），到点自动结束；说“别看了”提前停，设置卡片上也能「现在停止」。

点「现在看一眼」可以立刻试一次。

后端进程需要 macOS「屏幕录制」权限：系统设置 → 隐私与安全性 → 屏幕录制，允许用来启动后端的终端（或 `start_sandrone.command` 所在的终端）。没有权限时卡片状态会显示截图失败。

## 每次检查做什么

后台每 30 秒检查一次是否到点，到点后依次判断，任一条不满足就不截图：

| 条件 | 不满足时 |
|---|---|
| 常开已开、或语音临时开还没到点；已同意；没有暂停 | 不看（临时开到点时清掉） |
| 前台应用她可以看（常开：不在不看的名单里；临时开：开始时的那个应用） | 不看，也不记录是哪个应用 |
| 键鼠空闲不到 5 分钟 | 视为离开，不看 |
| 有视觉模型 Key | 不截图 |
| 窗口画面和上次相比有变化（差值哈希距离 > 5） | 截了但不发视觉模型 |

通过后只截这个应用最前面的一个窗口（`screencapture -l`，不是整屏），缩到 1280 像素以内的 JPEG，在内存里发给视觉模型（与「看一眼」共用配置，留空复用对话模型的地址与 Key），要求只概括、不转录私密内容。截图不落盘。

视觉模型返回一句概括（她在做什么、值得留意的地方、是否值得关心、是不是游戏），存进 `screen_observations`，保留 7 天，可在卡片里一键清除。认出没建档的游戏时自动建档，下一次按游戏场景看。

## 她什么时候开口

满足下面全部条件时，才让她（对话模型 + 人设）决定要不要说一句：

- 开口频率不是「只看不说」，距她上次因看屏开口已超过设定间隔；
- 你最近 10 分钟没有和她聊天（聊着天时，看到的内容会进对话上下文，不另外开口）。

她多数时候会选择不说。说的话写进主时间线（网页对话里显示为「她主动发来」），并按设置弹一条 macOS 系统通知。

## 对话里的上下文

陪着看期间，最近 30 分钟内的最多 3 条概括会作为「你最近看到他在电脑上做的事」进入她的系统提示，所以你问「我刚才在干嘛」时她不需要再截图。

## 游戏场景（M15）

游戏档案可以不手动加：看一眼或陪着看时认出的游戏会自动建档（安静观众、不写战报，可以在「游戏」页改）。也可以在菜单 →「游戏」手动添加：选游戏窗口对应的应用、填别名（聊天里的叫法，如“尖塔”）、类型和屏幕上重点看什么，并**必须为她选一个陪玩角色**（角色只影响陪着看时她什么时候开口）：

| 角色 | 游戏中 | 每场上限 | 两句间隔 |
|---|---|---|---|
| 记录员 | 不说话，只写战报 | 0 | — |
| 安静观众 | 只在通关、打倒 Boss、阵亡后说一句 | 3 | 15 分钟 |
| 搭子 | 大事件或结算、阵亡、菜单、地图、读条时偶尔接话 | 6 | 8 分钟 |
| 教练 | 间隙给一两句具体建议，阵亡后复盘 | 8 | 5 分钟 |

- 常开时游戏应用照常在看的范围里；游戏中默认 2 分钟看一次，视觉模型输出画面类型（战斗/结算/阵亡/菜单/读条/地图/对话）、事件、进度和局面。**战斗画面永远不开口。**
- 游戏离开前台 15 分钟算一场结束：她把这一场压缩成战报（发进对话，可关），更新**账号档案**与**里程碑**，把值得长期记住的事写进这个游戏的记忆，并把看到的通用规律整理进**游戏知识**。
- **分游戏的长期记忆**：记忆带 `scope`（`game:<id>`）。在某场游戏中、或聊天提到游戏名/别名时，新记忆归到该游戏，检索时同游戏记忆加分；聊别的时，不相关的游戏记忆不会被唤起。
- 正在玩或聊到某个游戏时，她的上下文里有账号档案、最近里程碑、本场所见、相关的游戏知识和最近两场战报，并要求机制、数值只说有把握的，拿不准就直说或搜索后说明出处。
### 两份资料：游戏知识 + 账号档案

| | 游戏知识 | 账号档案 |
|---|---|---|
| 内容 | 规则、机制、数据、高手思路、常见误区 | 你的进度、拥有的角色/卡牌/装备、当前配队、资源养成、目标、卡关点、偏好、里程碑 |
| 存放 | 仓库 `knowledge/games/<文件>.md`（随 Git 分享） | 本机数据库（`game_profiles.save_card`、`game_milestones`） |
| 个人信息 | 绝不包含；写入时还会去掉带 UID/QQ 号的行 | 只属于你 |

两份都**主要由她维护**：

- 每场结束：战报的同一次整理里，她更新账号档案、记里程碑，并把对所有玩家成立的规律（不含你的信息）整理进游戏知识；画面上出现打倒 Boss、通关、解锁、升级时自动记一笔里程碑。
- 聊天或通话中：每轮回复之后，后台任务判断这轮是否涉及某个游戏（正在玩或提到了它），由她决定要不要更新账号档案、记里程碑、把有把握或有来源的通用规律记进知识。原来是对话里的两个工具，每次调用要多跑一整轮模型（实测从约 4 秒变成 16 秒），已移到回复之后。
- 游戏页「让她去查」：搜索（设置的服务，没读到可用网页时改用 DuckDuckGo）→ 并行读前几个网页、用 `web_fetch` 只提取与主题相关的规则和高手打法 → 整理进知识文件。一次约 1–2 分钟。
- 游戏页「导入我的笔记」：她把笔记拆开，通用部分整理进知识，你个人的部分合并进账号档案。

整理知识文件时她重写整份文件（16000 token 预算），数值标来源编号，并按来源可信度取舍：网页正文 > 陪玩观察 > 笔记/聊天 > 搜索摘要；只有笔记支持的说法注明“玩家心得，未经资料印证”，与网页矛盾时以网页为准并写进“常见误区”。原始资料与旧版本只存在本机 `data/games/<id>/`；删除游戏时这些会删掉，知识文件留在仓库。格式与分享规则见 `knowledge/games/README.md`。

## 状态提示

对话页标题下会显示「在看 XXX」或游戏中的「在看你玩 XXX」，表示她陪着看时最近一次看的是哪个应用；暂停、离开或在范围外应用时不显示。卡片里可以「暂停 1 小时」，语音临时开时还能「现在停止」。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/PUT | `/api/companion/config` | 读取/保存；同意截图外发带 `consent: true`，结束语音临时开带 `stop_watch: true`；返回 `watch_until` / `watch_apps` |
| POST | `/api/companion/pause` | `{minutes}`，0 表示恢复 |
| GET | `/api/companion/status` | 当前状态（off / paused / not_allowed / away / no_window / watching / playing / error） |
| GET | `/api/companion/apps` | 正在运行的普通应用名 |
| POST | `/api/companion/check` | 立刻看一眼设置页后面最前面的、她可以看的窗口 |
| GET/DELETE | `/api/companion/observations` | 读取/清除观察概括 |
| GET/POST | `/api/games` | 游戏列表 / 添加（必须带 `role`） |
| GET/PUT/DELETE | `/api/games/{id}` | 详情 / 修改（含账号档案、别名） / 删除 |
| GET | `/api/games/roles` | 陪玩角色 |
| GET | `/api/games/{id}/sessions` | 场次与战报 |
| GET | `/api/games/{id}/memories` | 她关于这个游戏的长期记忆 |
| GET/POST | `/api/games/{id}/milestones` | 里程碑 / 手动记一条 |
| DELETE | `/api/games/{id}/milestones/{mid}` | 删除一条里程碑 |
| GET/PUT | `/api/games/{id}/knowledge` | 游戏知识文件与来源 / 直接编辑 |
| POST | `/api/games/{id}/research` | `{topic}`：联网查资料并整理进知识 |
| POST | `/api/games/{id}/notes` | `{title, text}`：导入笔记（通用进知识、个人进档案） |

实现：`backend/app/services/tools/screen.py`（看一眼），`backend/app/services/screen_companion.py`（陪着看：调度、判断、开口、语音临时开），`backend/app/services/games/`（档案与角色、游戏场景、自动识别 `detect.py`、场次战报、记忆归属），`backend/app/services/tools/windows.py`（JXA 读窗口与前台应用、ioreg 读空闲时长、单窗口截图、差值哈希），测试 `backend/tests/test_screen_companion.py`、`test_screen_unified.py`、`test_game_companion.py`、`test_game_knowledge.py`、`test_web_tools.py`。
