# 游戏知识（可分享）

每个游戏一份 Markdown 文件（文件名优先用英文名，如 `slay-the-spire.md`），记录**游戏本身**的规则、机制、数据，以及高水平玩家的打法思路和常见误区。陪玩时她只取与眼前局面或问题相关的几节来用。

这些文件主要由她维护：

- 「陪你玩游戏」页里让她按主题查资料：搜索 → 读前几个网页、只提取相关要点 → 整理进文件；
- 导入笔记：通用部分进这里，你个人的部分进本机数据库里的账号档案；
- 每玩完一场，她把看到的通用规律记进来；聊天里她也会随手记下有把握的知识。

每次整理她会重写整份文件，数值后面标来源编号，末尾列出来源链接；旧版本备份在本机 `data/games/<id>/knowledge.prev.md`。你也可以直接编辑这里的文件。

## 分享与贡献

欢迎把整理好的文件提交到仓库。提交前请确认：

- **不含任何个人信息**：玩家 ID/UID、昵称、账号、某个人的进度/阵容/资源；
- 具体数值有来源编号，来源一节列出了链接；
- 用自己的话总结，不要大段照抄原文。

## 格式

```markdown
# 《游戏名》游戏知识
> 最后整理：YYYY-MM-DD；涉及版本：…
## 概览
## 规则与机制
## 角色 / 卡组 / 流派
## 关卡与 Boss
## 高手思路
## 常见误区
## 版本与改动
## 来源
- [1] 标题 — https://…
```
